# AI Boost — идеи применения ИИ в вашей нише

Скилл Никиты Русанова для разбора профессии или ниши: где ИИ поможет экономить время, привлекать клиентов и собирать отдельные инструменты в рабочую систему.

На входе — ниша, боли и цели. На выходе — конкретные сценарии применения ИИ, 4–6 инструментов, 4–5 неочевидных связок и первые шаги для внедрения.

## Установка

Скачайте репозиторий:

```bash
git clone https://github.com/rusanovproject-dotcom/ai-boost-skill.git
```

Для Claude Code выполните из корня своего проекта:

```bash
mkdir -p .claude/skills/ai-boost
cp ai-boost-skill/skills/ai-boost/SKILL.md .claude/skills/ai-boost/SKILL.md
```

Для Codex выполните из корня своего проекта:

```bash
mkdir -p .agents/skills/ai-boost
cp ai-boost-skill/skills/ai-boost/SKILL.md .agents/skills/ai-boost/SKILL.md
```

Откройте новую сессию ассистента после установки.

## Пример запроса

```text
Используй ai-boost.
Ниша: риелторы, вторичная недвижимость.
Боли: много времени на объявления, холодные обращения и повторные касания.
Цель: больше квалифицированных заявок и меньше рутины.
Пол: мужской.
Предложи конкретные сценарии применения ИИ, неочевидные связки
и план первого внедрения. Допущения и расчётные цифры помечай явно.
```

Можно начать с одной ниши: скилл запросит недостающий контекст.

## Что внутри

- [SKILL.md](skills/ai-boost/SKILL.md) — исходный скилл без изменений.
- Правила конкретики, схема клиентского цикла и проверка качества результата.
- Демонстрационный пример для фотографа.

Скилл опубликован в исходном виде. Упоминание `nikita-writer` относится к авторскому стилю; отдельный пакет с таким названием сюда не входит. Основные правила голоса перечислены внутри скилла. Упоминание офиса из 13 агентов — часть исходной авторской роли, а не требование к вашей установке.

Оценки времени, денег и конверсии в примерах служат иллюстрациями. Результаты разбора — гипотезы: проверяйте их на данных своей ниши, сверяйте актуальность инструментов и не выдавайте расчёты за подтверждённые результаты.
